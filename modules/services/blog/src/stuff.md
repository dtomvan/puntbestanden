# Stuff on this domain

Well, at least the parts that aren't solely for me, I guess.

- [cs.toostveen.nl](https://cs.toostveen.nl): an mdbook for my CS notes (or at least, the public parts)
- [fs.toostveen.nl](https://fs.toostveen.nl): a tiny [copyparty](https://copyparty.eu) instance, which I use to probably send you little snippets of code or something
- [md.toostveen.nl](https://md.toostveen.nl): a [HedgeDoc](https://hedgedoc.org/) instance, for sharing markdown files and collaborating on them
- [git.toostveen.nl](https://git.toostveen.nl): a [Forgejo](https://forgejo.org) instance, which is a self-hostable GitHub alternative. Used for sharing Git repositories.
- [u.toostveen.nl](https://u.toostveen.nl): a [Chhoto](https://chhoto.link/) instance, which is a simple url shortener. So when I send you links like <https://u.toostveen.nl/lpl> you know where that comes from :)
